# Petunjuk Jalankan Program - Modul 07

## Persiapan
1. Pastikan Node.js (versi 18 atau lebih baru) sudah terinstal.
2. Pastikan struktur folder berada di dalam `latihan-praktikan/`:
   - `latihan-praktikan/soal-01/`
   - `latihan-praktikan/soal-02/`

## Cara Menjalankan Server
1. Jalankan `JALANKAN.bat` atau buka terminal di folder ini lalu ketik:
   node server.cjs
2. Biarkan terminal tetap berjalan.

- Soal 02: http://127.0.0.1:3007/latihan-praktikan/soal-02/
